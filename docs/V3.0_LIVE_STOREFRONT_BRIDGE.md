# TOOLIXA V3.0 — Live Storefront Bridge

## What changed
- `/api/site/config` reads the `commandCenter` SiteSetting when a database is configured and returns only an explicit allowlist of public brand fields.
- Values are normalized: colors must be six-digit hex, font is allowlisted, radius is clamped, and text is length-limited.
- Public Workbench requests the endpoint and applies returned branding. Database failure safely falls back to default branding.
- Private settings, custom CSS, analytics identifiers, ad identifiers, roles, plans and logs are never returned by the public config route.

## Publish theme changes
1. Configure `DATABASE_URL` on the server and apply Prisma migrations.
2. Sign in to `/admin`.
3. Change brand identity/theme values and use the admin save action.
4. Open the public site in a fresh session and check the brand and theme.

If database saving is unavailable, the admin panel uses browser storage only. Those changes are not published to other visitors. The public API returns defaults if the database is unavailable.

## Verification
Run `npm ci`, `npm run db:generate`, `npm run test`, and `npm run build`. Live DB persistence must be verified against an actual PostgreSQL instance before production launch.
